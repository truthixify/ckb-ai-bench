Task (blockhash): Use the MCP tool rpc_get_block_hash with the JSON argument {"block_number": 1} to read the block hash of block number 1. The result is a 0x-prefixed hex string (it may be returned wrapped in double quotes). Write ONLY that hash value (the 0x-prefixed hex string, without surrounding quotes) into a file named proof_blockhash.txt in the current directory. Do not write anything else to that file.
