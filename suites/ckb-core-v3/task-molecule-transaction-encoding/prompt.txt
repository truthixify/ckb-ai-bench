Build an executable at `build/release/molecule-transaction` that accepts `INPUT_JSON OUTPUT_JSON`.
The input contains one canonical CKB JSON-RPC `raw_transaction`. Serialize the RawTransaction using
the canonical Molecule schema, then write exactly
`{"hash":"0x...", "serialized":"0x..."}`. The hash is CKB Blake2b-256 over the serialized raw
transaction. Support multiple inputs, cell deps, header deps, optional type scripts, and output
data. Do not serialize witnesses into the raw transaction hash.
