Task (JavaScript state-transition script): Implement a CKB type script in JavaScript. The script applies to every cell in its type group. Each group input and group output must contain exactly 8 bytes encoding an unsigned little-endian integer. The group must contain the same non-zero number of inputs and outputs, and output value i must equal input value i plus one without wrapping.

Use the CKB JavaScript bindings provided by ckb-js-vm. Keep the source and a Makefile in the current directory. `make build` must bundle the source with the pinned esbuild tool, compile it to QuickJS bytecode at `build/release/state-transition.bc` with the pinned ckb-js-vm binary and `ckb-debugger`, and work without network access. The required tools are available under `$CKB_SDK_HOME` and on `PATH`.
